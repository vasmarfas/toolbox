# vasmarfas

Личный сайт и бесплатный мультитул в одном приложении. Одна кодовая база на Kotlin Multiplatform /
Compose Multiplatform собирается в сайт на WebAssembly ([vasmarfas.com](https://vasmarfas.com),
[vasmarfas.ru](https://vasmarfas.ru)) и в нативные приложения для Android, iOS, Windows, macOS и Linux.

**English:** [`README.md`](README.md) · **Поддержать:** [`SUPPORT.md`](SUPPORT.md) ·
**Приватность:** [`privacy-policy.md`](privacy-policy.md) · **Условия:** [`terms.md`](terms.md)

## Что внутри

Страница-визитка с контактами, проектами, статьями и резюме — и каталог офлайн-инструментов в 13
категориях с поиском, избранным и недавними. Всё, что считается локально, работает везде, сокеты и
датчики — там, где их даёт ОС, и каталог помечает каждый инструмент поддерживаемыми платформами.

| Категория | Примеры |
|---|---|
| Сеть | ping (ICMP/TCP/HTTP), traceroute, сканер портов и локальной сети, DNS поверх HTTPS и UDP, whois/RDAP, калькулятор подсетей, HTTP-запросы, TLS-сертификаты, тест скорости, Wake-on-LAN, интерфейсы и Wi-Fi |
| Конвертеры | единицы измерения, системы счисления, объёмы данных, валюты, кулинарные меры, размеры одежды, числа прописью, римские цифры |
| Калькуляторы | инженерный и программистский, проценты, чаевые, скидки и НДС, кредит, сложный процент, ИМТ, топливо, закон Ома, резисторы, светодиоды, сечения проводов, соотношения сторон |
| Текст | регистр, счётчики, строки, поиск и замена, транслитерация, Морзе, шифры, сравнение, очистка, Unicode, ASCII |

| Безопасность | генератор и проверка паролей, утечки (HIBP, k-анонимность), TOTP, случайные данные, сравнение контрольных сумм |
| Цвет и дизайн | конвертер цветов, палитры, контраст, схемы Material 3, градиенты, QR и штрихкоды, типографика, CSS-единицы |

## Стек

Kotlin 2.4, Compose Multiplatform 1.12, Material 3 Expressive (`MaterialExpressiveTheme`,
`MotionScheme`, `WideNavigationRail`, `ShortNavigationBar`, wavy-индикаторы), navigation-compose с
привязкой к истории браузера, Ktor 3, kotlinx-serialization, kotlinx-datetime, material-kolor (схема
из seed-цвета, динамические цвета на Android 12+), qrose (QR и штрихкоды). Веб — только `wasmJs`.
